Лабораторная работа № 2. Шифрование файлов и папок

Постановка задачи
Реализовать защиту данных пользовательских папок и файлов, находящихся в папке, а также подпапках путем шифрования. Для доступа к данным исходной папке необходимо выполнить дешифрование.

Требования:
Интерфейс: консольное приложение
Реализация основного класса для шифрования/дешифрования как Singleton
Рекурсивный обход папок для шифрования всех вложенных файлов
Входные данные: путь к папке, пароль для шифрования


Используемые библиотеки
cryptography
Основная криптографическая библиотека для Python.

Используемые Модули:

Fernet - симметричное шифрование (AES-256 в режиме CBC с HMAC)
PBKDF2HMAC - функция деривации ключа из пароля
hashes.SHA256() - хеш-функция для PBKDF2

Используемые библиотеки Python

os - работа с файловой системой, рекурсивный обход (os.walk)
sys - получение пути к скрипту (sys.argv[0])
base64 - кодирование ключа для Fernet

Реализация паттерна Singleton
Что такое Singleton
Singleton - порождающий паттерн проектирования, который гарантирует, что у класса есть только один экземпляр, и предоставляет глобальную точку доступа к нему.
Реализация в проекте
pythonclass CryptoManager:
    _instance = None
    _initialized = False

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

    def __init__(self):
        if not CryptoManager._initialized:
            CryptoManager._initialized = True
            self.script_path = os.path.abspath(sys.argv[0])

Почему ленивая инициализация?
Ленивая инициализация (Lazy Initialization) - объект создается только при первом обращении к классу, а не при загрузке модуля.

Преимущества:

Экономия ресурсов - если класс не используется, объект не создается
Контроль момента создания - можем управлять инициализацией
Возможность передачи параметров при создании
Избежание проблем с порядком инициализации модулей

Как работает:
python# При импорте модуля
from file_encryptor import CryptoManager
# _instance = None (объект еще не создан)

# При первом вызове
crypto = CryptoManager()  # Создается объект
# _instance теперь содержит объект

# При повторных вызовах
crypto2 = CryptoManager()  # Возвращается тот же объект
# crypto is crypto2 → True
Зачем _initialized:
Python вызывает __init__ каждый раз при создании объекта, даже если объект уже существует. Флаг _initialized гарантирует, что код инициализации выполнится только один раз.

Описание функций
_get_key(password, salt)
Преобразует пароль пользователя в криптографический ключ фиксированной длины (32 байта для AES-256).
Параметры:

password - пароль пользователя (строка)
salt - соль, 16 случайных байт

Возвращает: ключ в формате base64 (требование библиотеки Fernet)
Алгоритм:

Использует PBKDF2 с 100,000 итерациями
Применяет SHA-256 для хеширования
Защищает от brute-force атак

_is_script(filepath)
Проверяет, является ли файл самим скриптом.
Защита от самошифрования: сравнивает абсолютный путь файла с путем к запущенному скрипту.
_is_encrypted(filepath)
Проверяет, зашифрован ли файл этой программой.
Как работает: читает первые байты файла и проверяет наличие маркера b'ENCRYPTED'.
Защита от повторного шифрования: если маркер найден, файл пропускается.
encrypt_file(filepath, password)
Шифрует один файл.
Алгоритм:

Проверка: не является ли файл самим скриптом
Проверка: не зашифрован ли файл уже
Генерация случайной соли (16 байт)
Создание ключа из пароля и соли
Чтение файла
Шифрование данных (Fernet/AES-256)
Запись: маркер + соль + зашифрованные данные

Формат зашифрованного файла:
[ENCRYPTED][соль 16 байт][зашифрованные данные]
Возвращает:

True - файл зашифрован
False - ошибка
None - файл пропущен (защита)

decrypt_file(filepath, password)
Расшифровывает один файл.
Алгоритм:

Проверка: не является ли файл скриптом
Чтение файла
Проверка наличия маркера (если нет - файл не зашифрован)
Извлечение соли из файла
Создание ключа из пароля и соли
Расшифровка данных
Запись исходных данных

Возвращает:

True - файл расшифрован
False - ошибка (неверный пароль)
None - файл пропущен

process_folder(folder, password, encrypt)
Рекурсивно обходит папку и обрабатывает все файлы.
Параметры:

folder - путь к папке
password - пароль
encrypt - True для шифрования, False для расшифровки

Использует: os.walk() для рекурсивного обхода всех подпапок.
